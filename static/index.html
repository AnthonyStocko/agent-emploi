Agent emploi

    CV maître

    Colle ici ton parcours complet : toutes tes expériences, réalisations chiffrées, compétences, formations, langues. Plus il est détaillé, meilleurs sont les CV adaptés. L'agent n'utilise que ce qui est écrit ici, il n'invente rien.

    Recherche

    France Travail

    Crée une application sur francetravail.io (API « Offres d'emploi v2 ») pour obtenir ces identifiants.

    Adzuna

    Clé gratuite sur developer.adzuna.com.

    Alertes mail (IMAP)

    Pour Gmail : serveur imap.gmail.com et un « mot de passe d'application », pas ton mot de passe habituel. La boîte est ouverte en lecture seule.

    Sauvegarde

    Sur Render sans disque persistant, la base est effacée à chaque redéploiement. Télécharge une sauvegarde régulièrement, puis restaure-la si besoin. Le fichier contient ton CV et tes identifiants : garde-le pour toi.
